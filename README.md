# ⚽ Football Performance Tracker

A web application for tracking football training sessions, match performance, fitness ratings, goals, assists, and personal progress.

## 🎯 Project Goal

The goal of this project is to explore how football performance data can be collected and analyzed to help players understand their progress and make better training decisions.

## ✨ Features

- Record football training sessions and matches
- Track goals and assists
- Log session duration and fitness ratings
- Add notes about each session
- View performance summaries and recent activity
- Save records in the browser using local storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Add training sessions and match records through the dashboard.
